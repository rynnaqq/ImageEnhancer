# Local Photo Enhancer v0.2.0 — Offline Restoration Preview

This update replaces the four “model not available in this build” restoration
dialogs with working, locally bundled tools. Requires Android 10 or later.

## Included

- Face detection and neural detail enhancement with YuNet and SwinIR, with strength
  control. Larger faces retain their original detail; previously reconstructed
  regions are protected.
- Learned black-and-white colorization with DDColor and adjustable strength.
- Automatic scratch detection and learned FP32 LaMa repair.
- Missing-area reconstruction with paint, erase and clear controls on the photo.
  Repair keeps unselected pixels and original alpha unchanged.
- Independent model readiness, complete hash verification and archived licenses.
- Protected-region tracking through resume and re-edit, with all restoration
  disabled by default in older projects.

All five model files are included in the APK. Processing remains offline with no
account, Internet permission or model download.

## Validation and limits

**20 core tests and 42 offline Android tests passed.** The optimized release and
release lint passed (zero errors, 30 warnings), along with signature, 16 KiB zip
alignment, model/hash/license and offline-permission audits. A same-key upgrade
from v0.1.0 retained the existing project and gallery result. In the signed app,
all five real model probes became Ready and a native workflow with all four
restoration tools completed and saved a result while preserving its source.

Android validation used an API 35 x86_64 emulator with 3,072 MiB RAM, airplane mode
on, Wi-Fi off and mobile data off. See the repository's
[restoration validation](https://github.com/rynnaqq/ImageEnhancer/blob/main/docs/RESTORATION_VALIDATION.md).

Colorization and repair require roughly 1.2 GiB of available memory. Sessions run
one at a time and report insufficient memory safely. The larger APK includes the
weights for fully offline operation. Reconstruction selections must cover at most
45% of a photo.

SwinIR is a general real-image detail model applied to face regions. Generated
detail, color and missing content are predictions, and are not claimed to recover
identity or historical truth. This remains a preview: physical ARM phones,
photographic quality, thermal behavior and huge inputs have not been qualified.
Reference fusion, TIFF and huge-raster streaming remain explicit dependencies.
