# Local Photo Enhancer v0.1.0 — Preview

Initial signed release of the native offline Android photo enhancer.
Requires Android 10 or later (API 29+); targets API 35.

## Included

- System photo/file import and independent batch processing.
- Local automatic enhancement, crop/rotate/flip/straighten, conventional
  noise/blur/clarity filters and tone/color controls.
- Bundled ONNX ESPCN super-resolution with overlapping tiles and CPU fallback.
- Immutable source copies, persistent projects, history and re-editable results.
- Foreground processing queue with pause/resume, cancellation and failure isolation.
- Before/after comparison, local sharing and new JPEG/PNG/WebP gallery exports.
- No Internet permission, accounts, telemetry or runtime model downloads.

## Installation and integrity

Download `LocalPhotoEnhancer-v0.1.0.apk` and `SHA256SUMS.txt` from this release.
Install the APK using Android's package installer, allowing installation from
the selected source when Android requests it. A prior debug build has a different
certificate; export any results you want to retain before uninstalling it.

## Validation and preview limits

The implementation passed 10 core tests and 22 offline Android integration/UI
tests on an owned Android 15/API 35 x86_64 emulator. The optimized release
assembled successfully. Its signed APK passes signature, 16 KiB ZIP alignment,
bundled-model/license and offline-permission verification.

The exact signed APK was also installed and operated in airplane mode through
the native system photo picker, automatic enhancement, background/return,
before/after comparison and gallery export. It saved a new 640×480 JPEG from a
320×240 synthetic PNG while the original source hash remained unchanged.

This is a working enhancement baseline. Advanced learned face restoration,
damage repair, colorization, reference fusion, TIFF and huge-raster streaming
remain explicit dependencies. The trained model restores 3× luminance; other
requested output scales resample that result and chroma is interpolated.
All performance profiles currently use the same trained model.

Physical-device quality, vendor acceleration, thermal/low-disk behavior and
large 48/108 MP workloads have not been qualified. Native runtimes are packaged
for arm64-v8a, armeabi-v7a, x86 and x86_64; packaging is not a tested device matrix.
See the repository's [validation record](https://github.com/rynnaqq/ImageEnhancer/blob/main/docs/VALIDATION.md)
and [technical dependencies](https://github.com/rynnaqq/ImageEnhancer/blob/main/docs/TECHNICAL_DEPENDENCIES.md).
